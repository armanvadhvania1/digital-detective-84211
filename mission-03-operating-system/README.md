4)My understanding-
* role of operating system: The OS acts as an intermediary layer between physical hardware and user applications, managing system resources safely and efficiently.

*Processes and PIDs: A process is an instance of a running program, uniquely identified by a Process ID (PID) that the OS uses to track and control system execution.

*Paths and Permissions: Absolute paths provide the full directory route from the root folder, whereas relative paths point to a location relative to the current working directory. File permissions regulate whether users or owners can read, write, or execute files.
