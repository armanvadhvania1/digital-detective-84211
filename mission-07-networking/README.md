4)My Understanding:
*Network concepts & packet switching: Networks range in scale from local (LAN) to wide geographical areas (WAN), moving data in small packets across routers using agreed communication protocols.
*Connectivity & DNS:** A connectivity test shows whether packets reach a target and return, while DNS resolves human-readable domain names into IP addresses so a client can reach the right server.
*Website loading flow:** A client enters a URL, resolves the domain via DNS, sends protocol-formatted requests across routers to a server, and renders the returned response.
